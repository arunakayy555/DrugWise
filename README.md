# DrugWise
A full-stack web app that detects and displays drug-to-drug interactions. Built with Node.js, Express, PostgreSQL, and Next.js, it lets users select multiple drugs and view interaction details with severity levels. Designed for quick, reliable, and user-friendly medication safety checks.
---------
The backend is deployed on **Vercel**.

🔗Base URL:
[https://drug-interaction-checker-ak-git-main-aruna-kalyans-projects.vercel.app](https://drug-interaction-checker-ak-git-main-aruna-kalyans-projects.vercel.app)

Available API Endpoints

| Method | Endpoint | Description |
|--------|-----------|-------------|
| `GET` | `/api/drugs` | Fetch all available drugs in JSON format |
| `GET` | `/api/interactions` | Fetch all known drug interactions |
| `POST` | `/api/interactions` | Check interaction between selected drugs |

Example Usage:
- [https://drug-interaction-checker-ak-git-main-aruna-kalyans-projects.vercel.app/api/drugs](https://drug-interaction-checker-ak-git-main-aruna-kalyans-projects.vercel.app/api/drugs)  
- [https://drug-interaction-checker-ak-git-main-aruna-kalyans-projects.vercel.app/api/interactions](https://drug-interaction-checker-ak-git-main-aruna-kalyans-projects.vercel.app/api/interactions)
